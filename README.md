## Overview
MDSE (**M**ultimodal **D**isaster **S**ituation **E**xplainer) is a multimodal vision-language framework for generating detailed and context-aware descriptions of underground mining disaster scenes. The goal is to improve situational awareness in harsh, low-visibility, and safety-critical underground environments.

This repository contains the implementation and resources associated with the paper:

> **Explaining the Unseen: Multimodal Vision-Language Reasoning for Situational Awareness in Underground Mining Disasters**
